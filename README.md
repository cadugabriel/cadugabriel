## 🤖 Engenharia de Dados na era da IA

O que está mudando a forma de construir plataformas de dados, e o que eu já uso no dia a dia:

* **Squads semi-agênticas:** assistentes de IA orquestrados com **CrewAI e LangGraph** para validar schemas, monitorar qualidade de dados e gerar testes automatizados nos pipelines.
* **LLMs no ciclo de desenvolvimento:** revisão de código, debugging assistido, AI pair programming e prompt chaining aplicados à engenharia de dados.
* **Resultado:** pipelines entregues mais rápido e com mais qualidade, com a IA cuidando do trabalho repetitivo para o time focar no que é arquitetura e decisão.

## 🚀 O que eu faço

* **Arquitetura de dados moderna:** Data Lake, Lakehouse (Medallion com Delta Lake), Data Warehouse e ambientes analíticos em **Azure e AWS**.
